Retail Sales Dashboard

Report build in progress
  • Power BI
  • Power Query (M)
  • DAX
  • Python
  • Synthetic data

The problem

A 20,550-row retail sales file full of deliberate mess, and four questions a manager would ask: how fast revenue and profit are growing, which categories, regions and channels drive them, where margin is strong or weak, and how big the returns problem is.

What I did

Cleaned the file in Power Query, fixing nine kinds of mess. Built a date table and DAX measures for revenue, profit, margin, returns and year-on-year comparisons.

Wrote a seeded Python script that generates the dataset so anyone can reproduce it.

What I found

Electronics brings in 34% of revenue on the thinnest margin, 25%. Beauty (62%) and Clothing (57%) earn far more per sale. November and December made up 27% of 2025 revenue. London is the largest region and online the biggest channel.
